# 安卓控制台

基于 Tauri（桌面应用框架）、React（界面组件库）和 TypeScript（带类型检查的编程语言）的 Windows（微软桌面系统）应用。

当前提交提供可构建的桌面骨架、简体中文和英语资源，以及即时保存的语言切换。界面文本集中在前端语言资源中。

## 本地开发

```powershell
npm ci
npm run tauri dev
```

使用 npm（前端包管理器）安装锁定的依赖并启动桌面窗口。使用 `npm run build`（前端构建命令）检查类型并打包前端。

候选项目为 scrcpy（安卓投屏工具）、Tango（投屏协议实现）、ScrcpyKeyMapper（可视化键位编辑器）和 QtScrcpyCore（投屏控制核心库）。本阶段未引入这些项目的源码或二进制文件。后续集成时按实际锁定的版本记录来源与许可证。
