> 本文保留早期设计与效果图。主导航、设备设置、投屏外框和输入实现已随后续迭代调整，当前使用方式见[项目说明](../../../README.md)，验收结果见[覆盖记录](./coverage.md)。

[交互式效果图索引](./gallery.html) · [上游功能覆盖清单](./coverage.md)

面向本地个人使用，沿用 Windows（微软桌面系统）、Tauri（桌面框架）、React（界面组件库）、TypeScript（带类型的编程语言）和 Rust（系统编程语言）。界面参照 Alaya（参考项目）的暗灰紫、雾紫高亮、细边框和文楷字体。截图作为 QtScrcpy（图形化安卓投屏工具）的功能分区参考。其设备列表、启动配置、数据线和无线连接、调试输出，在这里按操作频率和所属对象重新安放。 [参考项目功能说明](https://github.com/barry-ran/QtScrcpy#interface-button-introduction)

## 一、左侧可折叠导航

- **设备**是首页。列表合并呈现连接状态与投屏状态，每行提供打开、聚焦、停止和更多。双击按该设备上次成功的配置开窗。数据线授权、无线配对和已知地址放在一个连接对话框。
- **投屏配置**管理可复用的启动配置。常用项直接展示，其他按视频与音频、画面来源、输入与设备、窗口与文件、连接和调试分组。选择目标设备后可直接启动。音频转发、后台录制、服务连接模式等由上游同一会话的参数控制。
- **工具**收纳设备能力查询、后台录制、仅音频、仅控制、无调试键鼠模式和诊断。每个工具先选明确目标，需要长期运行的任务在设备行显示运行与停止。调试输出按设备折叠，提供复制实际参数和本次错误详情。
- **设置**固定在底部。简体中文、英语、保存目录、默认配置、投屏引擎更新和回退集中于此。设置即时保存，本地配置文件足够。

默认窄栏仅显示图标，展开显示图标和文字。常用图标在鼠标悬停和键盘焦点时显示操作提示，提供本地化的可访问名称。操作不可用时提示原因，例如设备未授权。配对、选项名称、输入框、风险确认保留文字。手机窗口的工具栏同样用图标与提示，按钮按下态和工具可用性以当前会话为准。

## 三、独立手机窗口

**官方窗口**作为日常默认。控制台启动官方 scrcpy（安卓投屏引擎），上游进程负责视频、声音、键鼠、文件拖放和原生快捷键。录制从启动配置开启。控制台负责开窗、聚焦和停止，保留上游支持的窗口和输入行为。后台录制和仅音频等无视频窗口的任务在工具入口启动。 [窗口说明](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/window.md) · [快捷键](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/shortcuts.md) · [录制说明](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/recording.md)

**增强窗口**为每台手机创建单独的桌面窗口。贴边工具条和视频区属于同一窗口，支持折叠、最小化和关闭。常用操作为截图、全屏、置顶、熄屏、返回、主页。更多菜单放音量、最近任务等。首批增强功能是画面、触控和截图，音频、录制和特殊设备模式优先走官方窗口。两种窗口模式共用设备列表，切换时结束旧会话。

## 四、底层实现

1. **设备和任务。** 后端用 ADB（安卓调试桥）发现设备，区分未授权、离线、在线与运行中的会话。使用设备连接标识和进程句柄隔离每台手机。无线配对地址和连接地址分开校验，配对码用后清除。连接关闭只回收本次任务。设备别名、上次参数和窗口位置写入一个带版本的本地配置，变更即时保存。
2. **配置和执行。** 以版本化参数目录描述名称、类型、默认值、冲突、平台和设备前提。用户选项编译成参数数组，后端确定引擎、目标设备、会话资源和文件路径。高级区提供命令预览与受控参数输入。低频参数走同一执行入口。查询和无窗口任务独立管理，停止录制时走正常退出流程。
3. **增强协议与输入。** Tango（投屏协议库）辅助进程与版本匹配的手机服务通信，压缩画面经有界通道送到网页视图解码。按实际画面矩形做坐标变换。旋转等待新尺寸，焦点离开或切换会话时释放触点。官方 5.0.1 独立窗口已实测。增强路线的 3.3.3 已通过浏览器探针；5.0.1 测试库存在适配项，仍需在真实桌面窗口复测。 [内部协议](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/develop.md#protocol)
4. **自动更新。** 后台获取官方稳定发行包，对照固定签名指纹验证清单，再核对文件哈希，成功才暂存。会话空闲时切换，保留上一可用包。增强组合独立锁定，实机通过才升级。 [上游校验方法](https://github.com/Genymobile/scrcpy/blob/master/doc/verify-release.md)

## 五、实施及验收

1. **先实现设备页、导航与官方会话。** 验收连接授权和配对、双击开窗与聚焦、有线和无线各一台同时运行、独立关闭、带录像正常退出。
2. **加入配置、工具和更新。** 用官方 5.0.1 帮助输出核对每个参数归属。验收查询、摄像头、虚拟显示、后台录制及无调试模式的可用提示。验证签名不匹配、中断下载、会话进行中和回退。能启动的选项再按设备前提验证结果。
3. **接增强窗口。** 先复测 5.0.1 的桌面画面、旋转与双指触控。再验收贴边工具条的缩放、双屏位置和焦点行为。双语资源同步维护，验收提示、错误和重启后的偏好。
