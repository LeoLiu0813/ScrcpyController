# 安卓控制台 0.2.2

修复控制键在其他窗口松开后，手机投屏仍误认为按住，导致普通点击或拖动出现两个落点的问题。

## 修复与改进

- 自动同步物理已经松开的左右修饰键，覆盖后台松开、窗口切换和鼠标激活流程；真实仍按住的按键会保留。
- 修饰键同步与侧栏组合快捷键按顺序投递，避免互相打断；消息投递失败时会重试。
- 每个投屏窗口独立维护状态，并校验注册代次，避免旧窗口关闭后的处理影响新窗口。
- 控制日志新增“同步修饰键释放状态”，记录原因与投递结果，不采集普通输入文字；关闭日志记录不会关闭输入保护。
- 命令行增加 `release-modifiers`（同步修饰键释放）和 `click-pointer`（不移动鼠标的原地点击）接口。

## 验证

三十八项自动测试通过；一项需要额外官方文件及本地签名工具的既有测试未运行。前端类型检查、构建及差异格式检查通过。

小米普通投屏完成六次“先读到控制键残留，再激活窗口并首次点击”的定向对照，全部保持单触点；关闭日志记录的对照也通过。独立连续采样共八千六百零一条，采样中未观察到第二触点；无日志的一次对照通过其内部状态验证，不包含在该连续采样中。

## 下载与运行

下载 `ScrcpyController-v0.2.2-windows-x64.exe`（微软桌面系统六十四位单文件程序）并运行。系统需要 WebView2（微软网页渲染运行库）；现有设备资料及投屏引擎继续保存在本机。

附带 `SHA256SUMS.txt`（安全哈希算法校验文件），用于核对下载文件的完整性。
