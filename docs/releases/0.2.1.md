# 安卓控制台 0.2.1

修复投屏窗口切换焦点后点击落点偏移，以及标题栏提示变化时窗口按钮微动的问题。

## 修复

- 恢复手机画面焦点时不再发送伪造的中心鼠标移动消息，避免下一次点击落到画面中心，或向拖动路径插入错误坐标。
- 标题栏右侧窗口按钮固定位置，中间提示独立居中；长提示与窄窗口不会挤动按钮。
- 焦点恢复日志补充本投屏窗口内的真实鼠标局部坐标和画面尺寸，仍明确区分系统采样与播放器实际处理结果，不记录其他应用里的鼠标位置。

## 验证

小米普通投屏已完成原地切换焦点、真实拖动窗口、置顶开关和更多菜单开关对照。修复前可复现鼠标位置被替换为画面中心；修复后两轮采样中的静止鼠标坐标均与播放器缓存一致。

前端类型检查和构建通过，三十一项自动测试通过；一项需要额外官方文件和本地签名工具的既有测试未运行。标题栏经过不同窗口宽度、中英文提示及显示缩放的布局验证，五个控制按钮的坐标和尺寸保持一致。

## 下载与运行

下载 `ScrcpyController-v0.2.1-windows-x64.exe`（微软桌面系统六十四位单文件程序）并运行。系统需要 WebView2（微软网页渲染运行库）；投屏引擎及现有设备资料继续保存在本机。

附带 `SHA256SUMS.txt`（安全哈希算法校验文件），用于核对下载文件的完整性。
