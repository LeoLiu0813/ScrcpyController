# 安卓控制台 0.2.0

新增循环内存控制日志，修复移动投屏窗口后部分区域无法点击的问题。

## 控制日志

- 从「设置 → 控制日志」查看、开关和导出诊断记录。
- 默认使用十六兆字节内存环形缓冲，满额自动覆盖最早记录；普通记录不持续写磁盘，只有主动导出才保存文件。
- 按系统送达的消息记录鼠标移动、按下、抬起和双轴滚轮，包含桌面、窗口客户区及视频区坐标。
- 记录窗口启停、侧栏动作、组合键投递、焦点恢复和几何刷新；不同手机窗口采用独立匿名编号。
- 采集范围限定在投屏窗口及其捕获的拖动，不记录输入文字、剪贴板、截图、设备身份，也不自动上传。

日志在退出或重启后清空。遇到异常时，请先导出日志再重启。系统按键状态和消息投递结果不代表播放器已完成处理。

## 窗口输入修复

- 移动、跨屏或缩放后强制同步播放器的窗口几何信息，避免沿用旧的输入区域。
- 纯位置同步不额外抢键盘焦点，也不需要通过可见尺寸变化刷新。

## 验证

前端类型检查与构建通过，三十一项自动测试通过。小米窗口已完成拖动、负坐标跨屏、缩放和鼠标记录验证，移动后原失效区域经实际点击确认恢复；两台手机的日志会话区分也已验证。

## 下载与运行

下载 `ScrcpyController-v0.2.0-windows-x64.exe`（微软桌面系统六十四位单文件程序）并运行。系统需要 WebView2（微软网页渲染运行库）；首次投屏可从设置安装官方投屏引擎。

附带 `SHA256SUMS.txt`（安全哈希算法校验文件），用于核对下载文件的完整性。
